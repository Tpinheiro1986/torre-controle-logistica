PAINEL DE AUDITORIA - como usar
===============================
Rode na maquina que enxerga o drive Y:. Sempre preencha LOGIN_EMAIL e
LOGIN_SENHA no topo de auditoria.py (entre aspas).

BOTOES (dois cliques):
  ATUALIZAR_DIARIO.bat  -> uso do dia a dia. Le SO os arquivos novos
                           (alterados desde a ultima vez), envia ao
                           Supabase, publica no GitHub e fecha. Rapido.
  EXECUTAR_AUDITORIA.bat-> carga COMPLETA (reprocessa tudo de 2026+).
                           Use so na 1a vez ou se precisar refazer do zero.
  ATUALIZAR_PAINEL.bat  -> so atualiza a tela com o que ja esta no banco
                           (sem varrer pastas). Util para ver mudancas de
                           layout e para consertar o link da capa.

AGENDAR TODO DIA (sem clicar):
  Agendador de Tarefas do Windows -> Criar Tarefa Basica ->
  Acao: Iniciar um programa -> Programa: o caminho do ATUALIZAR_DIARIO.bat
  -> defina o horario (ex.: 07:00). Pronto: atualiza sozinho todo dia.

COMO FUNCIONA O INCREMENTAL:
  O programa guarda a data da ultima execucao no arquivo .ultima_sync.
  Na vez seguinte, so olha os arquivos alterados a partir dali (com 2 dias
  de margem). Assim nao reprocessa tudo - so o que entrou de novo.

OBS: o painel publicado fica em auditoria/ na RAIZ do repositorio (mesmo
nivel de otd/, scorecard/). O programa copia o painel pra la sozinho.
